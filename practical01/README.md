Ключові спостереження:

* Мінімум `concavity_mean`, `concave_points_mean`, `concavity_se` = 0 — це **не

## 12. Робочі гіпотези (перевіряються в ЛР № 1)

1. **`_worst` + увігнутість — найкорисніші предиктори.** `concave_points_worst`,
   `perimeter_worst`, `radius_worst`, `area_worst`, `concave_points_mean`
   ($|r|\approx 0.74$–$0.80$). Перевірка: коефіцієнти лінійної моделі / ознаки Lasso.
2. **Кластери `radius/perimeter/area` надлишкові.** 15 пар $|r|>0.95$. Гіпотеза:
   Ridge/Lasso або відбір одного представника з кластера дадуть таку саму якість
   при стабільніших коефіцієнтах. Перевірка: CV-RMSE на 30 ознаках vs скорочений набір.
3. **Частина ознак — шум для лінійної моделі** (`fractal_dimension_mean`, `*_se`
   симетрії/текстури, $|r|<0.1$). Гіпотеза: їх виключення не погіршить CV-RMSE.
   Перевірка: абляційний експеримент.
4. **Правоасиметричні `_se` виграють від `log1p`.** `area_se` skew ≈ 4.8,
   Спірмен (−0.72) ≫ Пірсон (−0.57). Перевірка: CV `StandardScaler` vs
   `log1p + StandardScaler`.
5. **`RobustScaler` може бути кращим за `StandardScaler`** через хвости. У базовому
   pipeline фіксуємо `StandardScaler`, `RobustScaler` — альтернатива для CV у ЛР № 1.

## 13. План попередньої обробки

| Ознака / проблема | Рішення | Обґрунтування |
|---|---|---|
| Пропущені значення | нічого не робимо | пропусків немає |
| Дублікати | нічого не робимо | дублікатів немає |
| Службові / ID / категоріальні стовпці | немає | усі 30 ознак числові неперервні |
| IQR-викиди (~3.9 % значень) | **залишаємо** | предметно валідні великі злоякісні ядра, корелюють з `diagnosis` |
| Права асиметрія `_se` (skew до 5.1) | базово залишаємо; **гіпотеза `log1p`** для ЛР № 1 | Спірмен ≫ Пірсон |
| Різні масштаби (≈ 10⁵) | **`StandardScaler`** у `ColumnTransformer` | регресія з регуляризацією чутлива до масштабу |
| Мультиколінеарність (15 пар $\|r\|>0.95$) | у препроцесингу не чіпаємо; **регуляризація / відбір** у ЛР № 1 | видалення ознак — це моделювання, рішення за CV |
| `SimpleImputer(median)` у pipeline | додаємо «про запас» | захист на випадок пропусків у нових даних; на цих даних — no-op |

Порядок: `raw → SimpleImputer(median) → StandardScaler → [модель, ЛР № 1]`.

## 14. Реалізація та перевірка pipeline

`ColumnTransformer([("num", Pipeline([SimpleImputer(median), StandardScaler]), 30 ознак)])`
(розділ 12 ноутбука). `fit_transform` — лише на train, `transform` — на test.

Перевірки:

* розмірність: train `(455, 30)`, test `(114, 30)` — кількість ознак не змінилась
  (кодування не застосовувалось);
* назви ознак після препроцесингу: `num__radius_mean` … `num__fractal_dimension_worst`
  — префікс `num__` додає `ColumnTransformer`, після його зняття перелік збігається
  з вихідними 30 ознаками;
* `NaN` після перетворення: 0 і в train, і в test;
* train: `max|mean| = 0.0`, `min std = 1.0` (стандартизація коректна);
* test: `mean ≈ 0.03` — і **не має** бути рівно 0, бо параметри взяті з train
  (відсутність витоку даних);
* той самий `preprocessor` застосовується до train і test.

Артефакти для ЛР № 1 збережено: `data/preprocessor.joblib` (навчений
`ColumnTransformer` + метадані спліту), `data/split_processed.npz`
(`X_train/X_test/y_train/y_test` + назви ознак).

## 16. Висновки

1. **Основні властивості набору.** 569 × 30, повністю числовий, без пропусків,
   дублікатів, категоріальних і службових ознак. Помірний дисбаланс класів
   (63 / 37). Ознаки — три агрегати (`_mean`, `_se`, `_worst`) 10 морфометричних
   характеристик ядра.
2. **Проблеми якості / структури.** (а) різномасштабність ≈ 10⁵; (б) сильна
   мультиколінеарність — 15 пар $|r|>0.95$, кластер `radius/perimeter/area`;
   (в) виражена права асиметрія `_se`-ознак (skew до 5.1).
3. **Найцікавіші розподіли / зв'язки.** Функціональний зв'язок `radius`–`perimeter`–`area`
   (`r` до 0.998); `radius`–`texture` практично незалежні; правий хвіст `_se`.
4. **Потенційні викиди.** ~3.9 % значень за IQR, майже всі — у `_se` та `area_worst`.
   Перевірка показала: це злоякісні об'єкти з великими неоднорідними ядрами →
   **залишаємо**, застосовуємо стійке масштабування.
5. **Ознаки, пов'язані з ціллю.** Сильно: `concave_points_worst`, `perimeter_worst`,
   `concave_points_mean`, `radius_worst`, `area_worst` ($|r|\approx 0.74$–$0.80$).
   Слабко: `fractal_dimension_mean`, `smoothness_se`, `symmetry_se`, `texture_se`.
6. **Сформульовані гіпотези.** 5 гіпотез (розділ 12): про найкорисніші ознаки,
   надлишковість кластерів, шумові ознаки, `log1p` для `_se`, вибір scaler.
7. **Застосований preprocessing.** `SimpleImputer(median)` (захисний) +
   `StandardScaler`, зібрані в `ColumnTransformer`; `fit` лише на train. Більше
   нічого — бо більше нічого не потрібно.
8. **Виключені ознаки.** Жодної. На відміну від прикладу Titanic, тут немає
   службових чи високо-кардинальних стовпців. Відбір ознак відкладено до ЛР № 1
   як частину моделювання.
9. **Відтворюваність.** `random_state=42` скрізь; pipeline — єдиний об'єкт;
   артефакти збережено; ноутбук виконується від початку до кінця без помилок.
